# Correspondances SDL complémentaires propres à Artouste.
#
# Ce fichier est chargé APRÈS assets/gamecontrollerdb.txt et le remplace pour
# les GUID qu'il redéfinit. Il sert à corriger ou à compléter la base
# communautaire sans la modifier, pour que celle-ci reste remplaçable telle
# quelle par la dernière version publiée sur SDL_GameControllerDB.
#
# Rappel de syntaxe (une manette par ligne) :
#   GUID,Nom,a:b2,b:b1,x:b3,y:b0,leftx:a0,lefty:a1,...,platform:Linux,
# où aN désigne un axe, bN un bouton et hN.M une direction de chapeau.
#
# ATTENTION : GLFW rejette une correspondance entière dès qu'elle cite un
# élément absent de la manette (par exemple righty:a4 sur une manette qui n'a
# que quatre axes). La manette est alors vue comme un simple joystick, sans
# aucune commande reconnue. Il faut donc n'y faire figurer que des numéros
# réellement présents.
#
# Pour relever ces numéros sur une manette non reconnue :
#   ./build/bin/gamepad_probe
# La sonde affiche le GUID, le nombre d'axes, de boutons et de chapeaux, et
# l'état brut en direct : il suffit d'actionner chaque commande pour lire son
# numéro.

#

#   a0  manche gauche/droite        cyclique latéral (leftx)
#   a1  manche avant/arrière        cyclique longitudinal (lefty)

#   a3  manette des gaz             collectif (RT)
# Boutons
#   b0  gâchette                    tir du mode zombie (R3)
#   b1  bouton du pouce             tenu + torsion : regard du pilote (L3)
#   b2  haut, arrière gauche        mode assisté (LB)
#   b3  haut, arrière droit         atterrissage automatique (RB)
#   b4  haut, avant gauche          position de départ (X)
#   b5  haut, avant droit           vue 3D (Y)
#   b6  socle, haut gauche          pause (Back)
#   b7  socle, haut droit           turbine : démarrer/couper (Start)
#   b8  socle, milieu gauche        livrée (A)
#   b9  socle, milieu droit         HUD, 4 modes (B)
#   b10 socle, bas gauche           sans action
