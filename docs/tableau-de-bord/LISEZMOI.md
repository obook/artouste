# Tableau de bord de l'Alouette II - documents de référence

Ce dossier rassemble les documents qui ont servi de référence pour modéliser la
planche de bord (le tableau de bord, ou "panel") de l'Alouette II dans Artouste.
Ils sont fournis à titre documentaire et pédagogique.

## Fichiers

| Fichier | Description |
|---------|-------------|
| `board.jpg` | Photographie du tableau de bord réel d'une Alouette II. |
| `al2m2.jpeg` | Manuel de vol, figure 2-5 : "Instrument panel and control pedestal" (appareils n. 1327 et antérieurs), page 2-13. |
| `al2m2b.jpeg` | Manuel de vol, figure 2-5a : même planche pour les appareils n. 1328 et ultérieurs, page 2-13b. |
| `al2m3a.jpeg` | Manuel de vol, légende de la figure 2-5a : les 71 repères des instruments et commandes, page 2-13a. |
| `al2m10.jpeg` | Manuel de vol, appendice 1, figure 1-1 : "Instrument markings" (graduations des cadrans : badin, pas collectif, double tachymètre, jauge carburant, indicateur triple). |
